## What the numbers do not say

- A review count measures files added, not the effort or quality behind them. The verdict and scope in each file
  say what was actually checked.
- Every review here is a static, AI-assisted reading of a pull request diff. None of it is a guarantee that a PR is
  safe, and none of it replaces the maintainers of the reviewed project.

## Want to be listed?

Open a pull request that adds your `reviews/<pr>.json` files and a row to this table. Use your GitHub handle.
