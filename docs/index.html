Every pull request of ItsNotRexed/Leonida that someone here has security-reviewed, with the verdict, who checked it and how. Generated from the review files of this repository.

Loading the reviews.

How to read a verdict. "clean" means no malicious pattern was found within the scope written on the row. It is not a guarantee that a PR is safe. "scan-only" means a pattern scan, not a read. "notes" means no malicious code but something a maintainer should look at. "do-not-merge" means a real problem.

Every review is a static, AI-assisted reading of a diff. Nothing was executed. Open "How it was checked" on a row to see what was actually done.

Rows tagged "Automated" come from a monitor that matches patterns in added lines. Its findings are leads to look at, not conclusions. "Hide automated scans" leaves only the reviews an agent wrote up.
